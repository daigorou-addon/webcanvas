## 日本語

ブラウザだけで使える、画像とテキストの合成ツールです。インストール不要で、PC・スマホの両方で使えます。

**👉 [今すぐ使う](https://daigorou-addon.github.io/webcanvas/)**

すべての処理はお使いの端末内で行われます。画像やデータがどこかに送信されることはありません。

### 主な機能

- **画像**: ドラッグ＆ドロップで追加（複数枚OK）。切り抜き、左右・上下反転、不透明度、明るさ、コントラスト、ぼかし、モザイク、集中線、消しゴム（透明化）
- **テキスト**: 多数のフォント、袋文字（縁取り付き）、影文字、ネオン文字、中抜き、グラデーション、斜め文字、弧、右／左に向かって大きく、3D文字、ロゴスタイル見本
- **鉛筆・消しゴム**: 自由に描画
- **表・線・図形**: 表の行・列の追加／削除、各種図形（図形の中に画像を入れることも可能）
- **レイヤー**: 一覧で選択・並べ替え・削除
- **元に戻す／やり直し**
- **キャンバスサイズ**: プリセットまたは自由入力（最大 8000 px）
- **PNG保存**: 透明部分を保ったままダウンロード
- **表示テーマ切り替え** と **6言語対応**（日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español）

### 使い方

1. 画像をキャンバスにドラッグ＆ドロップします（画像なしで、サイズを選んでテキストなどから始めることもできます）。
2. 「ツール」から、鉛筆・テキスト・表・線・図形を選んで追加します。
3. 要素をクリックして位置・大きさ・回転・見た目を調整します。
4. 「PNGでダウンロード」で保存します。

## English

WebCanvas is a browser-based tool for combining images and text. No installation is required, and it works on both desktop and mobile.

**👉 [Try it now](https://daigorou-addon.github.io/webcanvas/)**

Everything is processed on your own device. Your images and data are never sent anywhere.

### Features

- **Images**: add by drag and drop (multiple images supported). Crop, flip horizontally/vertically, opacity, brightness, contrast, blur, mosaic, radial lines, and an eraser (make areas transparent)
- **Text**: many fonts, outline (with an extra border), shadow, neon, hollow, gradient, italic, arc, grow toward the right/left, 3D text, and a gallery of logo style presets
- **Pencil and eraser**: free-hand drawing
- **Tables, lines, and shapes**: add/remove table rows and columns, a variety of shapes (images can be placed inside shapes)
- **Layers**: select, reorder, and delete from the layer list
- **Undo / Redo**
- **Canvas size**: presets or custom size (up to 8000 px)
- **PNG export**: download with transparency preserved
- **Light/dark theme** and **6 languages** (日本語 / English / 한국어 / 简体中文 / 繁體中文 / Español)

### Usage

1. Drag and drop an image onto the canvas (you can also pick a canvas size and start with text or other tools).
2. Choose a pencil, text, table, line, or shape from "Tools" to add it.
3. Click an element to adjust its position, size, rotation, and appearance.
4. Click "Download as PNG" to save.
